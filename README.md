# Путівник командних лабораторних

Статична сторінка для команди, яка виконує лабораторні з «Вступу до спеціальності»:
що таке ЛР1 і ЛР2, хто за що відповідає, чеклист перед подачею, конструктори NFR і
user stories, перевірка ID у зведеному файлі.

Відкрити: https://gregory-ivd.github.io/lab-guide/

Без збірки й без залежностей: один файл `index.html`. Дані нікуди не надсилаються,
чеклист зберігається в браузері (localStorage). ЛР3 буде додано, коли з'являться матеріали.
Сторінка навчальна й не замінює методичку.
